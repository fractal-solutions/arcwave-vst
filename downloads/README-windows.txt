ArcWave v0.3.0 - Windows x64 VST3

1) Extract this ZIP.
2) Run install-vst3.bat (asks for admin), or add the extracted folder to
   FL Studio's VST3 search paths.
3) In FL Studio: Options > Manage plugins > Find plugins.

ArcWave uses your GMS wavetables if installed; otherwise it generates its own
original tables and works standalone.
