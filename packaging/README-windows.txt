ArcWave - Windows x64 VST3

1) Extract this folder.
2) Run install-vst3.bat (asks for admin), or add this folder to your DAW's
   VST3 search paths (no admin needed).
3) Rescan plugins. In FL Studio: Options > Manage plugins > Find plugins.

ArcWave uses your installed GMS wavetables when present; otherwise it generates
its own original tables and works standalone.
